Welcome to NeuroView AI 

To run the project, follow these steps:
For the Frontend:
    1. run : npm install
    2. run : npm run dev

For the Backend:
    1. cd backend
    2. run : python -m venv new_env
    3. run : new_env\Scripts\activate 
    or source new_env/bin/activate for Mac
    4. run : pip install -r requirements.txt
    5. run : uvicorn app.main:app --reload --port 8000
